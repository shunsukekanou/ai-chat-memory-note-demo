# AIチャット記憶・教本ノート

過去の AI チャット（Gemini / ChatGPT / Claude）の履歴を取り込んで保管し、1つずつ要約して「記憶（出来事・決めたこと）」と「教本（自分の好み・ルール・前提）」に育て、新しい相談のときに、どの AI にもそのまま貼れる「引き継ぎ文」を作る、自分専用のノートです。

- 保存先は、**自分のブラウザの中（IndexedDB）だけ**。運営側のサーバーはありません。
- ふだんは**外部へ何も送りません**。自分の API キーを設定に入れ、「自動で要約する」を押したときだけ、そのチャットの本文を、選んだ会社（Google / OpenAI / Anthropic）へ送ります。

## 動かし方
```
npm install
npm run dev     # http://localhost:5195
npm run build   # dist フォルダに出力
```

## 4つの画面
1. **取り込む**：Google データ エクスポート（マイ アクティビティの JSON／HTML）、ChatGPT・Claude の conversations.json をドラッグ＆ドロップ／ファイル選択。チャット1本分の貼り付け。お試し用の見本データ。Google の記録は、時刻の間隔（15分〜3時間）で会話のまとまりに分けます。
2. **整理する**：新しい順・キーワード検索・未要約フィルターで一覧。要約は2通り。
   - **やり方A（半自動）**：お願い文（履歴つき）をコピー → 普段の AI に貼る → 返事を貼り戻して保存（API キー不要・無料枠で可）。長い履歴は、12,000 字ごとに分けます。
   - **やり方B（自動）**：設定に自分の API キーを入れると、1件ずつ、またはまとめて自動で要約して振り分け。
   - 記憶・教本は、編集・削除・ピン留め（「いつも引き継ぎに含める」）ができます。
3. **引き継ぐ**：「今日相談したいこと」を入れると、言葉の重なりで関連する記憶を選び（件数を変えられる）、ピン留めした教本と組み合わせて、引き継ぎ文を1クリックでコピーできます。チェックで足す・外すも可能です。
4. **設定**：API の会社・モデル名・キー、バックアップの書き出し／読み込み（API キーは入りません）、全部消す。

## 限り・未確認
- 実際の自分の書き出しファイルでの読み取りは、確認していません（公開されている形式をまねた架空のファイルでの確認）。読めないときは、貼り付けで取り込めます。
- 実際の API キーでの通信は確認していません（通信を模した試験まで）。モデル名の初期値は、各社の最新の一覧で確かめていません。
- 要約の返事の読み取りは、「【記憶】」「【教本】」の見出しと、行頭の「-」「・」「番号」に対応します。
